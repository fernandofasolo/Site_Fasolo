# Copa do Mundo 2026 — Projeto Site Fasolo

Mini-plataforma de acompanhamento da Copa 2026, integrada ao site fasolo.ia.br.
Acesso em: `fasolo.ia.br/copa2026`

---

## Arquitetura

```
Site_Fasolo/
├── copa2026-backend/   # API Python (FastAPI + SQLite)
└── copa2026/           # Frontend React + Vite + Tailwind
```

| Módulo | Stack | Porta local |
|--------|-------|-------------|
| Backend | Python 3.11+, FastAPI, SQLite, uvicorn | 8000 |
| Frontend | React 18, Vite, Tailwind CSS, Zustand | 5173 |

---

## Como rodar localmente (qualquer PC)

### Pré-requisitos
- Python 3.11+
- Node.js 18+

### 1. Clonar / atualizar
```bash
git clone https://github.com/fernandofasolo/Site_Fasolo.git
# ou, se já tiver:
git pull origin main
```

### 2. Backend

```bash
cd copa2026-backend

# Criar e ativar virtualenv
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/Mac

# Instalar dependências
pip install -r requirements.txt

# Configurar variáveis de ambiente
copy .env.example .env          # Windows
# cp .env.example .env          # Linux/Mac
# edite .env e defina ADMIN_KEY

# Inicializar banco de dados (só na primeira vez)
python db/init.py

# Iniciar API
uvicorn main:app --reload --port 8000
```

API disponível em: http://localhost:8000  
Docs automáticos: http://localhost:8000/docs

### 3. Frontend

```bash
cd copa2026

# Instalar dependências
npm install

# Iniciar dev server
npm run dev
```

Frontend disponível em: http://localhost:5173/copa2026/

> O Vite faz proxy automático de `/api` → `http://localhost:8000`

## Rotina diária de atualização de resultados

1. Buscar os resultados do dia na web
2. Editar `copa2026-backend/db/seeds/02_jogos.sql`
   - Alterar `status` de `'agendado'` para `'encerrado'`
   - Adicionar `gols_a, gols_b` na linha do jogo
   - Se um jogo da mesma rodada ainda estiver agendado, **separar em dois INSERTs distintos**
3. Recriar o banco local para testar: `python db/init.py --reset`
4. Commit e push: `git add copa2026-backend/db/seeds/02_jogos.sql && git commit -m "fix: resultados DD/MM" && git push`
5. Em produção (Render), o banco é recriado automaticamente no próximo deploy ou via endpoint `/api/admin`

## Features implementadas

### Fase de Grupos (Jun 2026)
- **Tabela de Grupos** — 12 grupos com classificação ao vivo, jogos por rodada
- **Visão Geral** — grid 3×4 com todos os grupos compactos (clicável)
- **Potes** — distribuição dos potes do sorteio
- **★ Pontos Corridos** *(brincadeira)* — todas as 48 seleções rankeadas em tabela única, ordenadas por Pts > SG > GP > Ranking FIFA, com zonas coloridas (Líder / Pódio / Top 16 / Em disputa / Eliminados)
- **Tabela de Jogos** — 104 jogos com filtros por fase, grupo, status e data
- **Últimos Resultados / Próximos Jogos** — widgets na home
- **Elencos** — 48 seleções com elenco completo (Brasil detalhado)
- **Escalação** — montador de escalação do Brasil com drag & drop e formações
- **Bolão** — simulador com palpites da fase de grupos + bracket eliminatório
- **Admin** — painel protegido por chave para atualizar placares em tempo real

### Infraestrutura
- Backend FastAPI com SQLite — zero dependência de serviço externo
- Frontend Vite com proxy para API local
- Deploy backend: Render (db persistente em `/var/data/`)
- Deploy frontend: integrado ao build Astro do site principal via Vercel
